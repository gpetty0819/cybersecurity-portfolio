# Cloud-First SMB Security Assessment (Anonymized Case Study)

This repository contains an anonymized security assessment and phased remediation plan for a small-to-medium business (SMB) warehouse and office environment.

The environment is cloud-first, supports remote access, and operates without dedicated IT or security staff. The assessment was conducted during an operational downtime window to identify risk exposure and design remediation that minimized business disruption.

## Project Focus Areas
- Identity and access management (IAM)
- Backup and recovery resilience
- Network and endpoint exposure
- Handling of customer contact PII
- Risk-based remediation sequencing

## Scope & Constraints
- Live production environment
- No downtime tolerance during active operations
- Limited internal documentation
- Small user base with shared operational responsibilities

## Approach
A non-intrusive, discovery-first approach was used to:
- Identify assets and attack surface
- Assess identity, network, endpoint, and data risks
- Prioritize findings based on business impact
- Design a phased remediation plan aligned with operational realities

All details have been sanitized and generalized to protect confidentiality.

## Status

- Phase 1 (Identity & Access): In progress
- Phase 2 (Backup & Recovery): Designed
- Phase 2.5 (PII Containment): Designed

This repository is intended to demonstrate real-world security assessment methodology, judgment, and documentation practices rather than tool-specific implementation.
